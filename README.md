# A11W4

A simple portfolio landing page project built with HTML and CSS.

## Project Overview

This project displays a clean personal landing page for Md. Azijul Hakim with a minimal design and a "Coming soon" message.

## Files

- `index.html` — main page structure and styling

## How to Run

1. Open `index.html` in a browser, or
2. Use a local web server in the project folder:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

- HTML5
- CSS3
